# Agentic AI Security Lab

## Project Objective

This project is an intentionally vulnerable Agentic AI laboratory designed
to demonstrate and test security vulnerabilities in Agentic AI systems.

The architecture consists of:

Chatbot → RAG → Main AI Agent → Agent-to-Agent Communication → MCP → Tools

The project demonstrates vulnerable and secure implementations of the
OWASP Top 10 for Agentic Applications.

## Modes

- 🔴 Vulnerable Mode
- 🟢 Secure Mode

## Security Disclaimer

This project is intended for local security research and educational purposes.

It uses:

- Fake data
- Simulated sensitive actions
- Local services
- No production credentials
